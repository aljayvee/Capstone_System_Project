## 3. Caveats
- **Assumption on Credentials**: Assumed `root` with empty password (`""`) is the primary local MariaDB configuration. The connection pool implementation in `db.js` must read from `.env` with fallback parameters (`DB_HOST=127.0.0.1`, `DB_PORT=3306`, `DB_USER=root`, `DB_PASSWORD=`) to allow environment overrides.
- **Port Conflict Risk**: Express server will listen on port `5000`. If `server/dist/index.js` or another process is currently running on port `5000`, it will need to be stopped before starting `Backend/src/server.js`.
