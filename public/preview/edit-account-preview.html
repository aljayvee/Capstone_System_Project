Form Ergonomics & Architecture

Edit Account Information: Layout Options

Two ergonomic layout architectures for customer profile editing, engineered with smart dirty-state tracking, loss-aversion guards, and Maya/Foodpanda visual hygiene.

Option 1: Grouped Bento Cards with Sticky Action Dock
Structured cards separating Personal Identity from Contact Details, with a sticky thumb-zone Save button.
Recommended
Core Philosophy
Separates personal identity (name & birthdate) from contact info (email & mobile) into discrete cards. Features an ergonomic sticky action dock that stays reachable above the soft keyboard.
Key Ergonomics
  • Interactive Avatar Header: Circular avatar with camera edit badge and direct gallery picker modal.
  • Card 1 (Personal Identity): First Name, Middle Name, Last Name, and Birthdate with interactive date-picker modal.
  • Card 2 (Contact Details): Email with validation checkmark, and Mobile Phone with delivery-driver coordinate note.
  • Sticky Bottom Dock: Dynamic Save Changes (X Modified) button in solid Foodpanda Pink (#F62459).
Option 2: Seamless Stream with Live Profile Card
Obsidian dark mode (#000000) with a live customer identity card and unified input rows.
Sleek & Unified
Core Philosophy
Inspired by Apple ID and Maya's dark mode. Shows a live profile preview card that updates in real time as the customer types their name, followed by clean hairline-divided input rows.
Key Ergonomics
  • Live Identity Preview: Customer sees exactly how dispatchers and riders will view their name and avatar.
  • Single Unified Card: All fields housed inside one clean card with subtle 1px dividers, reducing visual fragmentation.
  • Inline Input Icons: Lucide vector icons (User, Mail, Phone, Calendar) anchored neatly inside each input line.
  • Full Theme Adaptation: Works flawlessly in both Maya True Black (#000000) and crisp Light mode.
