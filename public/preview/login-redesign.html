Unified Alert & Error Design System (All Layouts)

4-Tier Warning, Error & Security Feedback Architecture

Every alert state is structurally differentiated by severity, visual grammar, and actionable recovery cues rather than generic red error text.

1. Critical Error: Red accent hairline with icon, concise message, and 1-tap retry button.
2. Security Cooldown: Amber/Orange theme with live countdown timer pill for 429 rate limits.
3. Role Notice: Blue informational card for Rider/Customer accounts with QR code link.
4. In-Field Micro-Alert: Inline boundary validation preventing invalid submission before API calls.
