UI/UX Architecture & Selection

Customer App: Account & Profile Layout Options

Three distinct layout architectures for customer profile and account management, engineered to comply with Anti-AI-Slop standards, zero-jargon copy, and Maya/Foodpanda visual hygiene.

Option 1: Bento Modular Dashboard
Structured Bento tiles unifying identity, live delivery pinpoint preview, and security in a glanceable grid.
Recommended
Core Philosophy
Extends the proven Home Screen Bento language into the Account tab. Information is parsed in compact, high-contrast modules rather than endless scrolling tables.
Key Ergonomics
  • Interactive Identity Card: Prominent member avatar, verified status badge, and 1-tap "Edit Profile" action.
  • Live Delivery Pinpoint Tile: Mini-map thumbnail previewing the active default address in Tacurong with direct pinpoint changer.
  • Inline Preferences Bento: 2x2 grid for Quick Stats, Appearance (Dark/Light toggle), Security & Passwords, and Help Center.
  • Subtle Ghost Sign Out: Restrained outline button at the base, completely isolated from destructive primary buttons.
Style: Bento Mosaic
Scroll Depth: Minimal (1 Viewport)
Visual Density: High Signal
Option 2: Segmented Tab Inspector
Multi-tab navigation separating Personal Info, Saved Places, and System Settings into dedicated capsule panes.
High Focus
Core Philosophy
Inspired by macOS HIG and modern banking portals. Prevents vertical clutter by dividing dense profile forms, delivery pins, and preferences into 3 distinct tab segments.
Key Ergonomics
  • Header Hero: Clean profile banner with circular avatar, user name, phone number, and verified checkmark.
  • 3-Segment Capsule Bar: [ Profile & Info | Saved Places | Security & Settings ] with smooth animated indicator.
  • Inline Form Editing: Tap any pencil icon to edit Full Name, Phone, Email, or Birthdate directly without full-page navigation.
  • Contextual Stats: Completed Errands count and Saved Locations badge immediately visible in the active tab.
Style: Segmented Inspector
Scroll Depth: Zero (Paging)
Form Editing: Inline Instant
Option 3: Minimalist Dock & Cards
Obsidian dark mode with circular quick-action dock and grouped floating settings cards.
Clean & Muted
Core Philosophy
Tailored for deep dark mode (#000000) lovers. Features high-frequency quick-action circular shortcuts followed by clean, iOS-style grouped settings lists.
Key Ergonomics
  • Centered Avatar Spotlight: Hero avatar with subtle Foodpanda Pink accent ring and customer rating pill.
  • 4-Icon Quick Action Dock: Direct 1-tap circular buttons for Saved Places, Order Receipts, Notifications, and Security.
  • Grouped Settings Cards: Rounded-xl card blocks with Lucide line icons and disclosure chevrons.
  • High Contrast & Battery Efficient: True black background saves OLED battery life on mobile devices.
Style: Dock + Grouped Cards
Theme: Obsidian Black (#000000)
Ergonomics: Thumb-Friendly
