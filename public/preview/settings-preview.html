App Preferences & Security Architecture

Settings Screen: Layout Options

Two ergonomic layout architectures for customer preferences, notification controls, biometric security, and storage optimization, designed to Maya & Foodpanda standards.

Option 1: Bento Preference Dashboard (Light Mode)
Structured Bento cards with visual 3-card theme selector, biometric security, and storage meter.
Recommended
Core Philosophy
Clean, high-information-density cards with discrete functional groupings. Features tactile visual theme selection, real-time push notification toggles, and live storage meter feedback.
Key Ergonomics
  • Visual Appearance Selector: 3-card grid (Light, Dark, System Auto) with live mini-illustrations and check badge.
  • Granular Notification Toggles: Independent switches for Live Delivery Tracking and Dispatcher Chat.
  • Biometric Security & Permissions: Fingerprint / Face ID toggle and Location Permission quick status.
  • Storage & Cache Cleaner: Visual storage meter bar showing temporary cache with an instant 1-tap Clean action.
  • Operations Hub Status: Tacurong City logistics status pill and active application build details.
Option 2: Maya True Black Bento Hub (Dark Mode)
Pure #000000 true black canvas with #121826 bento containers, pink switches, and device session security.
High Contrast
Core Philosophy
Optimized for OLED displays with zero backlight bleed. Features Maya's signature True Black (#000000) backdrop, Foodpanda Pink active toggles, and deep security row controls.
Key Ergonomics
  • True Black Palette: Pure #000000 background with #121826 surface cards and 1px hairline borders.
  • High-Contrast Toggles: Foodpanda Pink (#F62459) active switches with smooth haptic feedback.
  • Security & Trusted Devices: Biometric unlock toggle plus a dedicated row for managing active device sessions.
  • Storage Breakdown: Segmented storage bar separating App binary from cached store images.
  • Tactile System Status: Green pulsing operational indicator for Tacurong City dispatch hub.
